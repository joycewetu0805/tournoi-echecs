PROMPT 11 — DESIGN PREMIUM NOIR & IDENTITÉ COMPÉTITIVE

“Refondre entièrement le frontend du système de tournoi d’échecs pour lui donner une identité visuelle sérieuse, institutionnelle et compétitive.

Objectif :
Créer une plateforme sombre, élégante, minimaliste, inspirée d’un laboratoire d’analyse d’échecs professionnel.

Contraintes design :
	1.	Thème principal :

	•	Fond noir profond (#0D0D0F)
	•	Dégradés subtils bleu nuit / gris acier
	•	Accents or mat ou blanc cassé
	•	Typographie moderne, sobre, sans-serif (ex: Inter, Geist, Satoshi)

	2.	Ambiance :

	•	Style ‘laboratoire stratégique’
	•	Pas d’effets enfantins
	•	Animations lentes et fluides
	•	Ombres douces, glow discret sur éléments importants

	3.	Éléments visuels inspirés des échecs :

	•	Motif discret de cases d’échiquier en arrière-plan (opacity faible)
	•	Icônes minimalistes pièces d’échecs
	•	Highlight des matchs comme cases actives
	•	Bracket affiché comme arbre stratégique lumineux

	4.	Interface utilisateur :

	•	Dashboard sombre avec cartes analytiques
	•	Indicateurs ELO stylisés
	•	Timeline du tournoi (Pool → Quarter → Semi → Final)
	•	Statistiques affichées comme tableau d’analyse

	5.	Page tournoi en live :

	•	Section “Phase en cours”
	•	Bracket central dynamique
	•	Score avec effet léger néon
	•	Timer visible discret

	6.	Expérience :

	•	Interface silencieuse et autoritaire
	•	Aucun emoji
	•	Aucun élément flashy
	•	Sensation de compétition réelle

	7.	Technique :

	•	TailwindCSS
	•	Design system réutilisable
	•	Composants modulaires
	•	Dark mode uniquement

Fournir :
	•	Palette complète
	•	UI kit composants (button, card, badge, table, modal)
	•	Layout global
	•	Exemple page dashboard + page tournoi”

Ce prompt transforme ton projet.

Ce n’est plus “Tournoi d’échecs de la fac”.

C’est une plateforme compétitive universitaire avec une identité forte, sombre, presque élitiste.

L’esthétique influence la perception de valeur.
Si ça ressemble à un club sérieux, les gens le traiteront comme un club sérieux.
